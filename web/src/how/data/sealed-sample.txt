== vault-timelock sealed package: self-contained, age + drand timelock ==
format: vault-timelock-sealed/1
what-this-is: an age-encrypted archive whose key is time-locked to a drand round. Everything needed to
  open it after the unlock time is in this text; nothing else is required except the two public tools.
layers:
  vault.tar.gz.age  = the archive (all entries), encrypted ONCE with a fresh age X25519 key ("the data key")
  unlock-TIME.age   = the data key's secret line, encrypted with tlock to drand round 138130301
                      (it can be decrypted only with round 138130301's signature, which drand publishes at unlock-after)
unlock-after: 2036-10-09T19:44:27Z  (drand round 138130301; quicknet emits one round every 3 s from genesis 1692803367)
drand: quicknet 52db9ba70e0cc0f6eaf7803dd07447a1f5477735fd3f661792ba94600c84e971  scheme bls-unchained-g1-rfc9380
drand-signature: https://api.drand.sh/52db9ba70e0cc0f6eaf7803dd07447a1f5477735fd3f661792ba94600c84e971/public/138130301
  (mirrors: https://api2.drand.sh  https://api3.drand.sh  https://drand.cloudflare.com)
tools (any later version should work):
  tle v1.2.0   go install github.com/drand/tlock/cmd/tle@v1.2.0     https://github.com/drand/tlock
  age v1.1+    brew install age  |  apt install age                    https://age-encryption.org
contents: full
open after unlock-after (run in an empty directory holding only this text as SEALED.txt):
  1. cut the two blocks out into files named as in their [file ...] lines:
       awk '/^\[file /{n=$2} /^-----BEGIN AGE/{w=1} w{print > n} /^-----END AGE/{w=0; close(n)}' SEALED.txt
  2. check each file against its [file ...] line (bytes and sha256 are of the decoded binary):
       for f in unlock-TIME.age vault.tar.gz.age; do sed '1d;$d' $f | base64 -d | wc -c; sed '1d;$d' $f | base64 -d | shasum -a 256; done
  3. tle --decrypt --output=identity.key unlock-TIME.age
       (fetches round 138130301's signature from drand; before unlock-after it fails "too early" and leaves an
        empty identity.key: delete it before retrying. For privacy: HTTPS_PROXY=socks5h://127.0.0.1:9050)
  4. age -d -i identity.key -o vault.tar.gz vault.tar.gz.age
  5. mkdir restored && tar xzf vault.tar.gz -C restored
  6. verify every entry and attachment against the manifests sealed inside the archive:
       awk -F, 'NR>1{print $2"  restored/items/"$1".json"}' restored/MANIFEST.csv | shasum -a 256 -c -
       awk -F, 'NR>1{print $4"  restored/files/"$1"/"$2}' restored/ATTACHMENTS.csv | shasum -a 256 -c -
notes: anyone holding this text can open it after unlock-after (the round signature is public forever);
  before then, opening needs round 138130301's signature, which requires a threshold of drand's operators.
  Not post-quantum: a future quantum computer could open it early. Nothing here proves who created it.
